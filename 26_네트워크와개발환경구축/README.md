# 26장. 네트워크와 개발환경 구축

WSL2와 리눅스 네트워크 기초를 다룬 과제입니다.

## 내용 요약

- WSL2 기능과 `ipconfig`(윈도우) / `ifconfig`(리눅스)로 각 환경의 IP 주소 확인
- SSH로 윈도우에서 WSL2로 원격 접속
- TCP/IP 4계층 구조와 TCP vs UDP 비교
- `ifconfig`, `netstat -antup` 결과의 각 항목이 의미하는 것 정리
- 양방향 ping 테스트로 네트워크 연결 확인
- 사설 IP + NAT 구조에서도 인터넷 접속이 가능한 이유

# ROS2-Robotics-Practice

ROS2(Foxy)와 로봇 SW 수업에서 진행한 실습 과제들을 정리한 저장소입니다. ROS2의 기본 개념(DDS, 토픽, 인터페이스, 파일시스템)부터 시작해서, C++ 클라이언트 라이브러리(rclcpp)로 직접 노드를 작성하고, 최종적으로 Jetson Nano 보드 + Dynamixel 모터 + 카메라를 이용한 실제 로봇 주행(라인 검출, 카메라 기반 원격 제어)까지 진행한 과정을 담고 있습니다.

## 배운 것 / 깨달은 것 / 성취한 것

ROS1과 ROS2의 가장 큰 차이가 "중앙 Master가 있느냐 없느냐"라는 것을 직접 실습하면서 체감했습니다. turtlesim으로 토픽·서비스·액션의 차이를 눈으로 확인하고, `rqt_graph`로 노드-토픽 연결을 시각화해보면서 추상적으로만 알던 pub/sub 구조가 실제로 어떻게 동작하는지 이해할 수 있었습니다.

rclcpp로 직접 퍼블리셔/서브스크라이버 노드를 작성하면서는, 콜백 함수를 어떻게 구성하느냐(일반 함수, 람다, `std::bind`)에 따라 코드 구조가 크게 달라진다는 것을 체감했고, C++ 고급 문법(스마트 포인터, `std::function`, 시간 리터럴)이 실제 ROS2 코드베이스 곳곳에서 왜 필요한지도 이해하게 되었습니다.

가장 크게 성장했다고 느낀 부분은 후반부 실습입니다. Jetson Nano에 카메라와 Dynamixel 모터를 연결하고, 카메라 영상을 ROS2 토픽으로 발행하는 노드와 그걸 구독해서 라인을 검출하고 모터를 제어하는 노드를 분리해서 설계해본 경험은, 단순히 "코드가 동작하는 것"을 넘어서 "여러 개의 독립적인 노드가 네트워크로 협력해서 하나의 로봇을 움직인다"는 ROS의 핵심 철학을 실제로 구현해본 값진 경험이었습니다.

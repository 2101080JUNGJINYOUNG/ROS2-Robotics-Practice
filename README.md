# ROS2-Robotics-Practice

ROS2(Foxy)와 로봇 SW 수업에서 진행한 실습 과제들을 정리한 저장소입니다. ROS2의 기본 개념(DDS, 토픽, 인터페이스, 파일시스템)부터 시작해서, C++ 클라이언트 라이브러리(rclcpp)로 직접 노드를 작성하고, 최종적으로 Jetson Nano 보드 + Dynamixel 모터 + 카메라를 이용한 실제 로봇 실습(키보드 원격 조작, 카메라 영상 기반 라인 검출)까지 진행한 과정을 담고 있습니다.

## 배운 것 / 깨달은 것 / 성취한 것

ROS1이 Master를 통해 노드를 중앙집중적으로 관리하는 것과 달리 ROS2는 DDS 기반의 분산형 통신으로 Master 없이 노드들이 서로를 찾는다는 구조적 차이를 과제로 정리해보고, turtlesim에서 `ros2 topic/service/action/node list`와 `ros2 interface show`로 토픽·서비스·액션의 개념과 인터페이스 구조를 직접 조회하고 `ros2 topic pub`으로 거북이를 직접 움직여봤습니다. `rqt_graph`로 노드-토픽 연결을 시각화해보면서, 추상적으로만 알던 pub/sub 구조가 실제로 어떻게 동작하는지 이해할 수 있었습니다.

rclcpp로 직접 퍼블리셔/서브스크라이버 노드를 작성하면서는, 콜백 함수를 어떻게 구성하느냐(일반 함수, 람다, `std::bind`)에 따라 코드 구조가 크게 달라진다는 것을 체감했고, C++ 고급 문법(스마트 포인터, `std::function`, 시간 리터럴)이 실제 ROS2 코드베이스 곳곳에서 왜 필요한지도 이해하게 되었습니다.

가장 크게 성장했다고 느낀 부분은 후반부의 두 가지 실습입니다. 하나는 Jetson Nano와 Dynamixel 모터를 연결해, 키보드 입력(전진·후진·좌우 회전)을 받아 속도 값을 토픽으로 발행하는 노드와 이를 구독해 실제로 모터를 구동하는 노드를 분리해서 설계한 원격 조작(teleoperation) 실습이고, 다른 하나는 카메라 영상을 ROS2 토픽으로 발행하는 노드(`pubpub`)와 그 영상을 구독해 OpenCV로 이진화·블롭 검출을 수행해 라인의 위치를 계산하는 노드(`subsub`)를 분리해서 설계한 라인 검출 실습입니다. 두 실습은 서로 다른 프로젝트였지만, 각각을 통해 "노드 하나가 입력을 받아 토픽으로 발행하면, 이를 구독한 다른 노드가 실제 동작(모터 구동, 영상 처리)을 수행한다"는 것을 직접 확인하면서, 여러 개의 독립적인 노드가 네트워크를 통해 협력해서 동작하는 ROS의 pub/sub 핵심 철학을 실제로 체감할 수 있었습니다.

# 1장. ROS와 ROS2

⬆ [ROS2-Robotics-Practice로 돌아가기](../README.md)  ·  📘 [공부하기](../공부하기/01_ROS와_ROS2/README.md)

ROS(로봇 운영체제)의 기본 개념을 정리한 과제입니다. 메타 운영체제, 소프트웨어 플랫폼, 미들웨어, 프레임워크의 차이를 정리하고, ROS2의 핵심 통신 기술인 DDS의 역할과 실제 자율주행 응용 사례를 조사했습니다.

## 내용 요약

- **소프트웨어 플랫폼**: 특정 프로그램이 실행되는 하드웨어+운영체제 조합 (예: 윈도우 11 + x86 CPU)
- **미들웨어**: 서로 다른 OS·언어로 만들어진 애플리케이션들이 데이터를 주고받도록 중간에서 통역해주는 소프트웨어
- **프레임워크**: 개발 효율을 위해 미리 정해진 구조("뼈대")를 제공하고, 제어의 흐름을 프레임워크가 가져가는(IoC) 개발 환경
- **메타 운영체제(Meta-OS)**: 여러 대의 컴퓨터·장치에 분산된 시스템을 하나의 단일 컴퓨터처럼 통합 관리하는 지휘 소프트웨어. ROS가 대표적인 예
- **DDS(Data Distribution Service)**: ROS2에서 노드 간 통신을 담당하는 미들웨어. 중앙 서버(Master) 없이 분산된 방식으로 노드들이 서로를 자동으로 찾아 통신(Discovery)하는 것이 핵심
- **자율주행 응용 사례**: Boston Dynamics Spot, LG전자 클로이 서빙로봇, Autoware 오픈소스 프로젝트

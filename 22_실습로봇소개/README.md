# 22장. 실습 로봇 소개

실습에 사용한 Jetson Nano 기반 로봇 플랫폼의 하드웨어 구성 요소를 조사한 과제입니다.

## 내용 요약

- **Jetson Nano**: GPU(128코어 Maxwell) + 쿼드코어 ARM A57 CPU, 4GB LPDDR4 메모리(대역폭 약 25.6GB/s)를 갖춘 저가형 엣지 AI/로보틱스 개발 보드
- **IMX219 카메라**: 해상도 3280×2464, 픽셀 크기 1.12µm, 광각 버전은 대각 175°까지 촬영 가능. 리눅스 장치 파일은 `/dev/video0`
- **CSI(Camera Serial Interface)**: 이미지 센서와 호스트 프로세서를 연결하는 인터페이스로, 여러 레인과 가상 채널을 지원해 멀티메가픽셀 센서의 대역폭 요구를 충족
- **GStreamer**: 리눅스 계열에서 비디오/오디오 파이프라인을 구성하는 오픈소스 멀티미디어 프레임워크 (스트리밍, 트랜스코딩, 카메라 캡처 등)
- **Dynamixel**: 위치·속도·토크 제어가 가능한 스마트 서보 모터. 모터+감속기+제어기+통신드라이버+센서가 하나로 통합된 로봇 관절 구동 모듈
- **U2D2**: Jetson Nano(USB)와 Dynamixel(UART)을 연결해주는 USB-UART 변환 장치. 리눅스 장치 파일은 `/dev/ttyUSB0`

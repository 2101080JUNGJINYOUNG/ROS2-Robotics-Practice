# 06장. ROS2 토픽 — 공부하기

이 챕터는 `geometry_msgs/Twist` 메시지와 `ros2 topic` 관련 명령어들을 이용해 turtlesim을 직접 제어하는 실습입니다. 아래 개념들만 알고 있으면 실습을 그대로 따라 하고 이해할 수 있습니다.

## 1. 토픽(Topic)이란 다시 정리

토픽은 "이름이 붙은 통신 채널"입니다. 퍼블리셔(Publisher)는 특정 이름의 토픽에 메시지를 계속 발행(publish)하고, 서브스크라이버(Subscriber)는 같은 이름의 토픽을 구독(subscribe)해서 메시지를 받습니다. 중요한 특징은 퍼블리셔와 서브스크라이버가 서로의 존재를 몰라도 된다는 것입니다(1:다 비동기 통신). 발행자는 "누가 듣고 있는지" 신경 쓰지 않고 그냥 토픽에 메시지를 쏘고, 구독자도 "누가 보내는지" 몰라도 그 토픽만 구독하면 메시지를 받을 수 있습니다.

## 2. `geometry_msgs/msg/Twist` 메시지 구조

Twist는 로봇의 속도를 표현하는 가장 대표적인 메시지 타입입니다. 필드는 다음과 같이 구성됩니다.

```
linear:
  x: 0.0   # 전/후 이동 속도 (앞으로 가는 힘)
  y: 0.0   # 좌/우 이동 속도 (옆으로 이동하는 로봇에서만 의미 있음, turtlesim/일반 바퀴 로봇에서는 보통 0)
  z: 0.0   # 상/하 이동 속도 (드론처럼 3차원 이동체가 아니면 보통 0)
angular:
  x: 0.0   # roll (좌우로 기울어지는 회전, 보통 0)
  y: 0.0   # pitch (앞뒤로 기울어지는 회전, 보통 0)
  z: 0.0   # yaw (제자리에서 좌우로 도는 회전) — 거북이/바퀴 로봇에서 실제로 쓰이는 값
```

turtlesim이나 일반적인 2륜 바퀴 로봇에서는 `linear.x`(전진/후진 속도)와 `angular.z`(회전 속도) 두 값만 실질적으로 쓰입니다. 나머지 4개 값은 3차원 공간에서 자유롭게 움직이는 로봇(드론 등)을 위해 존재하는 값이라고 이해하면 됩니다.

## 3. 토픽 상태를 확인하는 명령어들

```
ros2 topic list             # 현재 발행/구독 중인 토픽 이름 목록
ros2 topic list -t          # 토픽 이름과 함께 메시지 타입까지 표시
ros2 topic echo /turtle1/cmd_vel     # 해당 토픽에 발행되는 메시지 내용을 실시간으로 출력
ros2 topic bw /turtle1/cmd_vel       # 초당 대역폭(전송되는 데이터 크기) 확인
ros2 topic hz /turtle1/cmd_vel       # 초당 발행 빈도(주기) 확인
ros2 node list               # 현재 실행 중인 노드 목록
ros2 node info /teleop_turtle        # 특정 노드의 퍼블리셔/구독자/서비스 정보
```

`bw`(bandwidth)는 "얼마나 많은 데이터가 오가는지", `hz`(hertz, 주파수)는 "얼마나 자주 메시지가 발행되는지"를 각각 측정하는 도구입니다. 둘 다 실시간 시스템에서 통신이 원하는 만큼의 속도로 잘 이루어지고 있는지 점검할 때 씁니다. `hz`는 평균 rate뿐 아니라 최소/최대/표준편차까지 보여주는데, 표준편차가 크면 발행 주기가 불규칙하다는 뜻입니다.

## 4. `ros2 topic pub`으로 직접 메시지 발행하기

```
ros2 topic pub --rate 1 /turtle1/cmd_vel geometry_msgs/msg/Twist "{linear: {x: 2.0, y: 0.0, z: 0.0}, angular: {x: 0.0, y: 0.0, z: 1.8}}"
```

이 명령은 별도의 코드를 작성하지 않고도 커맨드라인에서 직접 토픽에 메시지를 발행하는 방법입니다. `--rate 1`은 초당 1번 발행한다는 뜻이고, 뒤의 중괄호(`{}`)는 YAML 형식으로 Twist 메시지의 필드 값을 채운 것입니다. `linear.x`가 양수(전진)이면서 `angular.z`가 0이 아니면(회전) 거북이가 원을 그리며 도는데, 이는 "전진하면서 동시에 방향을 계속 바꾸면 원 궤적이 된다"는 물리적으로 당연한 결과입니다. `linear.x` 값을 키우면 원이 커지고, `angular.z` 값을 키우면 회전이 빨라져서 원이 작아지는 식으로 값을 바꿔가며 실험해보면 Twist 메시지의 의미가 훨씬 명확해집니다.

## 5. 스스로 확인하는 질문

- `linear.x`와 `angular.z`가 실제로 거북이의 어떤 움직임에 대응하는가?
- `bw`와 `hz`는 각각 무엇을 측정하는 명령어인가?
- `ros2 topic pub` 없이 거북이를 원으로 돌게 하려면 코드에서 무엇을 발행해야 하는가? (18~20장 rclcpp 실습과 연결해서 생각해보기)

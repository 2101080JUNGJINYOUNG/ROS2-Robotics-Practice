## 문제 1. Twist 메시지 필드 해석

다음 실행 결과에서 6개의 숫자의 의미를 설명하라.

```
$ ros2 topic echo /turtle1/cmd_vel
linear:
  x: 2.0
  y: 0.0
  z: 0.0
angular:
  x: 0.0
  y: 0.0
  z: 0.0
---
```

<details>
<summary>정답 보기</summary>

linear은 선속도(직선 운동), angular은 각속도(회전 운동)를 의미합니다.

**linear (x, y, z)** — 위치의 변화율(병진 운동의 속도)
- x: x축 방향 속도. 양수(+)는 전진, 음수(-)는 후진
- y: y축 방향 속도. 양수(+)는 왼쪽 이동, 음수(-)는 오른쪽 이동
- z: z축 방향 속도. 양수(+)는 상승, 음수(-)는 하강

turtlesim에서는 x축(전진/후진)만 실제로 움직이게 되어 있습니다.

**angular (x, y, z)** — 축을 중심으로 한 회전 속도
- x (Roll): 전진 방향 축을 중심으로 한 회전
- y (Pitch): 좌측 방향 축을 중심으로 한 회전
- z (Yaw): 위쪽 방향 축을 중심으로 한 회전. 양수(+)는 반시계 방향, 음수(-)는 시계 방향 — turtlesim에서 실제로 쓰이는 값

</details>

## 문제 2. `ros2 topic bw` 결과 해석

다음 실행 결과에서 4개의 숫자(42B/s, mean, min, max)의 의미를 설명하라.

```
$ ros2 topic bw /turtle1/cmd_vel
Subscribed to [/turtle1/cmd_vel]
42 B/s from 2 messages
        Message size mean: 52 B min: 52 B max: 52 B
```

<details>
<summary>정답 보기</summary>

이 숫자들은 토픽의 데이터 전송량과 메시지 크기를 나타냅니다.

- **42 B/s**: 초당 평균 데이터 전송량(Bandwidth). 1초에 평균 42바이트가 전송되고 있음을 의미. 메시지 전송 간격이 1초보다 길면 이 값은 메시지 1개 크기보다 작을 수 있음
- **mean: 52 B**: 메시지 1개의 평균 크기
- **min: 52 B**: 전송된 메시지 중 가장 작은 크기
- **max: 52 B**: 전송된 메시지 중 가장 큰 크기

평균/최소/최대가 모두 같으므로, "항상 52바이트 크기의 고정된 형태 메시지가 전송되고 있다"고 해석할 수 있습니다.

</details>

## 문제 3. `ros2 topic hz` 결과 해석

다음 실행 결과에서 5개의 숫자(average rate, min, max, std dev, window)의 의미를 설명하라.

```
$ ros2 topic hz /turtle1/cmd_vel
average rate: 3.692
        min: 0.136s max: 0.775s std dev: 0.21953s window: 7
```

<details>
<summary>정답 보기</summary>

`ros2 topic hz`는 해당 토픽의 메시지가 얼마나 자주 발행되는지(빈도)를 측정합니다.

- **average rate: 3.692**: 초당 평균 발행 횟수(Hz). 1초에 평균 3.692개의 메시지가 발행됨
- **min: 0.136s**: 메시지들 사이의 가장 짧은 시간 간격
- **max: 0.775s**: 메시지들 사이의 가장 긴 시간 간격
- **std dev: 0.21953s**: 시간 간격의 표준편차 — 0이 아니므로 발행 간격이 완전히 고정되지 않고 약간의 변동이 있음을 의미
- **window: 7**: 계산에 사용된 샘플 개수 — 최근 7개의 메시지를 바탕으로 위 통계가 계산됨

</details>

## 문제 4. turtlesim 명령어 직접 실습

`turtlesim_node`를 실행하고 새로운 터미널 창에서 아래 명령어들을 (rosbag 제외) 순서대로 직접 실습하고, 명령과 출력 결과가 일치하는지 확인하라.

```bash
ros2 run turtlesim turtlesim_node
# 새 터미널에서:
ros2 run turtlesim turtle_teleop_key
ros2 node list
ros2 node info /turtlesim
ros2 topic list
ros2 topic list -t
ros2 run rqt_graph rqt_graph
ros2 topic echo /turtle1/cmd_vel
ros2 topic bw /turtle1/cmd_vel
ros2 topic hz /turtle1/cmd_vel
```

<details>
<summary>정답 보기 (원본 과제 기준 결과)</summary>

- `ros2 node list` → `/teleop_turtle`, `/turtlesim` 두 노드가 출력됨
- `ros2 node info /turtlesim` → Subscribers(`/turtle1/cmd_vel` 등), Publishers(`/turtle1/pose`, `/turtle1/color_sensor` 등), Service Servers(`/spawn`, `/kill`, `/turtle1/set_pen` 등), Action Servers(`/turtle1/rotate_absolute`)가 출력됨
- `ros2 topic list` → `/parameter_events`, `/rosout`, `/turtle1/cmd_vel`, `/turtle1/color_sensor`, `/turtle1/pose`
- `ros2 topic list -t` → 위 토픽 이름 옆에 각각의 메시지 타입(`geometry_msgs/msg/Twist`, `turtlesim/msg/Color`, `turtlesim/msg/Pose` 등)까지 표시됨
- `rqt_graph` → `/teleop_turtle`와 `/turtlesim` 노드가 `/turtle1/cmd_vel`, `/turtle1/pose`, `/turtle1/color_sensor`, `/turtle1/rotate_absolute`(액션) 등으로 연결된 그래프가 나타남
- `ros2 topic echo/bw/hz`의 결과는 문제 1~3에서 다룬 것과 동일한 형태로 나타남 — 명령의 목적과 실제 출력이 서로 일치합니다.

</details>

## 문제 5. `ros2 topic pub`으로 예측하고 검증하기

아래 명령을 실행하면 거북이가 어떻게 움직일지 먼저 예측해 본 뒤, 실제로 실행해서 확인하고 명령과 출력 결과가 일치하는지 설명하라.

```bash
ros2 topic pub --rate 1 /turtle1/cmd_vel geometry_msgs/msg/Twist "{linear: {x: 2.0, y: 0.0, z: 0.0}, angular: {x: 0.0, y: 0.0, z: 1.8}}"
```

<details>
<summary>정답 보기</summary>

`linear.x: 2.0`으로 전진하면서 동시에 `angular.z: 1.8`로 반시계 방향 회전을 하기 때문에, 거북이는 원을 그리며 이동합니다. `--rate 1`이므로 이 메시지가 1초에 1번씩 발행되며, 실제로 turtlesim 창에서 거북이가 원을 그리며 잘 도는 것을 확인할 수 있어 명령과 출력 결과가 일치합니다.

</details>

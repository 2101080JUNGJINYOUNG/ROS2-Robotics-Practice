## 1. ROS2를 설치하고 4~9페이지의 명령어 실행결과를 첨부하시오.

- **ROS2 패키지 설치확인** — 설치 후 다음 명령어를 실행하면 도움말이 출력되어야 함: `source /opt/ros/foxy/setup.bash` → `ros2 --help`
- **ROS 개발툴 설치 확인**: `source /opt/ros/foxy/setup.bash` → `colcon --help`
- **ROS2 패키지 예제 테스트** — 리눅스 터미널 창을 열고 `ros2 run demo_nodes_cpp talker` 실행(→ 'hello world: x' 문자열 전송), 새 터미널 창에서 `ros2 run demo_nodes_py listener` 실행(→ hello world: x 문자열 수신), 종료는 각각 Ctrl+c
- **ROS2 빌드 테스트** — `ros2_ws`라는 이름으로 워크스페이스(작업공간) 폴더를 생성한 후 빌드 명령어 `colcon build` 실행. 빌드 후 워크스페이스 폴더의 서브 폴더로 `src` 이외에도 `build`, `install`, `log` 폴더가 생성되는 것을 확인할 것

## 2. 11페이지 수정결과를 첨부하시오.

`~/.bashrc` 파일에 아래 내용을 추가/수정하시오.

```
source /opt/ros/foxy/setup.bash
source ~/ros2_ws/install/local_setup.bash

source /usr/share/colcon_argcomplete/hook/colcon-argcomplete.bash
source /usr/share/vcstool-completion/vcs.bash
source /usr/share/colcon_cd/function/colcon_cd.sh

export _colcon_cd_root=~/ros2_ws
export ROS_DOMAIN_ID=10
export ROS_NAMESPACE=robot1
export RMW_IMPLEMENTATION=rmw_fastrtps_cpp
export RCUTILS_COLORIZED_OUTPUT=1
export RCUTILS_LOGGING_USE_STDOUT=0
export RCUTILS_LOGGING_BUFFERED_STREAM=1
```

<details>
<summary>정답 보기</summary>

**[실행 결과]** 수정한 `.bashrc`를 실제로 반영한 결과는 다음과 같습니다 (`ROS_NAMESPACE`를 `jetson0`으로, `ROS_DOMAIN_ID`를 `0`으로 설정한 예시):

```
linux@JINYOUNG: $ cd
linux@JINYOUNG: $ source .bashrc
linux@JINYOUNG: $ echo $ROS_DOMAIN_ID
0
linux@JINYOUNG: $ echo $ROS_NAMESPACE
jetson0
linux@JINYOUNG: $
```

`.bashrc`를 수정한 뒤 `source .bashrc`로 다시 불러오면, 새로 지정한 환경변수(`ROS_DOMAIN_ID`, `ROS_NAMESPACE` 등)가 셸에 바로 적용되는 것을 확인할 수 있습니다.

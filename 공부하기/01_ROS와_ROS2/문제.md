## 1. 메타운영체제, 소프트웨어 플랫폼, 프레임워크, 미들웨어에 대하여 각각 설명하라.

<details>
<summary>정답 보기</summary>

**소프트웨어 플랫폼 (Software Platform)**

소프트웨어 플랫폼은 특정 프로그램이 실행되는 기반이 되는 하드웨어와 운영체제의 조합으로 구성된 '환경' 또는 '무대'를 의미합니다. 예를 들어 '윈도우 11'과 'x86 CPU'의 조합은 하나의 플랫폼이며, 개발자는 이 특정 플랫폼에서만 작동하는 소프트웨어를 만들게 됩니다. 따라서 어떤 플랫폼을 선택하느냐에 따라 애플리케이션의 구동 환경이 결정되므로 개발의 가장 기본적인 기준점이 됩니다.

**미들웨어 (Middleware)**

미들웨어는 서로 다른 운영체제나 프로그래밍 언어로 작성된 애플리케이션들이 원활하게 데이터를 주고받을 수 있도록 중간에서 다리 역할을 하는 '소프트웨어 통역사'입니다. 마치 해외에서 사용하는 만능 어댑터처럼, 미들웨어는 복잡한 통신 과정을 표준화하고 대신 처리해주어 개발자가 통신의 세부적인 구현에 신경 쓰지 않고 자신의 프로그램 로직에만 집중할 수 있도록 돕는 핵심적인 통신 소프트웨어입니다.

**프레임워크 (Framework)**

프레임워크는 소프트웨어 개발의 효율성을 위해 미리 정해진 구조적 '뼈대'와 규칙을 제공하는 개발 환경입니다. 개발자는 이 뼈대 위에 자신의 코드를 채워 넣는 방식으로 작업하며, 전체 프로그램의 제어 흐름을 직접 만들기보다는 프레임워크가 정해준 규칙에 따라 코드가 호출되는 '제어의 역전(IoC)' 개념이 특징입니다. 이는 일관성 있는 구조를 통해 개발 속도를 높이고 유지보수를 용이하게 만듭니다.

**메타 운영체제 (Meta-OS)**

메타 운영체제는 여러 대의 컴퓨터와 장치들에 분산된 시스템을 마치 하나의 단일 컴퓨터처럼 통합 관리하고 제어하는 '총괄 지휘 소프트웨어'입니다. 기존 운영체제(Linux, Windows 등) 위에 설치되어, 미들웨어를 활용한 통신, 하드웨어 추상화, 분산 프로세스 관리 등의 기능을 제공함으로써, 개발자가 물리적인 장치의 위치나 네트워크의 복잡성을 신경 쓰지 않고 전체 시스템을 하나의 단위로 다룰 수 있게 해줍니다.

</details>

## 2. DDS에 대하여 조사하고 ROS에서 DDS의 역할은 무엇인가?

<details>
<summary>정답 보기</summary>

DDS는 OMG(Object Management Group)에서 제정한 실시간 분산 시스템을 위한 데이터 통신 미들웨어 표준입니다. 가장 큰 특징은 중앙 서버나 브로커 없이 각 노드(프로그램)들이 서로를 자동으로 발견하여 직접 데이터를 교환하는 'Publish-Subscribe(발행-구독)' 모델을 따른다는 점입니다. 이 덕분에 중앙 서버 고장 위험이 없고, 데이터 전송 속도가 빠르며, 데이터의 중요도에 따라 '반드시 전달' 또는 '최신 데이터만 빠르게 전달' 등 전송 옵션을 세밀하게 제어하는 QoS(Quality of Service) 기능을 제공하여 높은 신뢰성과 실시간 성능을 보장합니다.

ROS 2에서 DDS는 분산된 여러 노드(로봇의 각 기능)들이 서로 데이터를 주고받을 수 있도록 하는 핵심 통신 계층, 즉 '신경계' 역할을 담당합니다.

</details>

## 3. ROS를 응용한 제품 또는 자율주행 프로젝트 사례를 3가지 이상 조사하라. 산업계에서 실제로 얼마나 많이 사용하는지 확인해볼 것

<details>
<summary>정답 보기</summary>

**1. 보스턴 다이내믹스 '스팟' (Boston Dynamics Spot)**

스팟은 세계적으로 가장 유명한 사족보행 로봇으로, 다양한 산업 현장에서 위험한 작업을 대신하거나 데이터를 수집하는 용도로 활약하고 있습니다. 보스턴 다이내믹스는 개발자들이 스팟을 더 쉽게 제어하고 새로운 기능을 추가할 수 있도록 ROS API를 공식적으로 지원합니다. 이를 통해 개발자들은 스팟의 센서 데이터를 ROS 표준 메시지 형태로 쉽게 받아보거나, ROS로 작성된 자율주행 및 객체 인식 알고리즘을 스팟에 바로 적용할 수 있습니다. 이는 ROS가 특정 로봇 하드웨어에 대한 제어와 응용 프로그램 개발을 얼마나 용이하게 하는지 보여주는 대표적인 사례입니다.

**2. LG전자 '클로이' 서빙로봇 (LG CLOi ServeBot)**

LG전자의 서빙로봇 클로이는 레스토랑, 병원, 호텔 등에서 자율적으로 주행하며 물건을 운반하는 서비스 로봇입니다. 클로이의 자율주행 시스템은 여러 센서로부터 데이터를 통합하고, 장애물을 피하며 최적의 경로를 찾는 복잡한 작업을 수행해야 합니다. LG전자는 이 시스템의 개발을 위해 ROS 2를 적극적으로 활용했습니다. ROS 2는 여러 통신 노드 간의 안정적인 실시간 데이터 교환이 가능하고(DDS 미들웨어 덕분), 시스템의 안정성을 높여주기 때문에 상업용 서비스 로봇의 핵심 소프트웨어 플랫폼으로 채택되었습니다.

**3. '오토웨어' 자율주행 오픈소스 프로젝트 (Autoware)**

오토웨어는 나고야 대학에서 시작되어 현재는 오토웨어 재단(The Autoware Foundation)이 이끄는 세계에서 가장 널리 사용되는 자율주행 오픈소스 소프트웨어입니다. 이 프로젝트 전체가 ROS를 기반으로 구축되었습니다. 오토웨어는 인지(Lidar, Camera), 판단(경로 계획), 제어(차량 조향) 등 자율주행에 필요한 모든 핵심 기능을 ROS 패키지 형태로 제공합니다. 전 세계 수많은 기업과 연구 기관들이 오토웨어를 활용하여 자체적인 자율주행 시스템을 개발하거나 테스트하고 있으며, 이는 ROS가 복잡한 자율주행 시스템을 구축하는 데 있어 사실상의 표준 프레임워크로 자리 잡았음을 증명합니다.

</details>
